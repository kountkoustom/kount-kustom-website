THE 5-LAYER MODEL

Design security around the threat.

01

THREAT IDENTIFICATION

Understand what can go wrong, where it can happen and what indicators appear before an incident.

02

DETECTION

Use cameras, sensors, access events, fire systems and other inputs to identify relevant conditions.

03

DECISION LOGIC

Define what the system should do for each verified condition instead of leaving every decision to a person.

04

RESPONSE

Trigger the appropriate hooter, flash, notification, access action or escalation path.

05

VERIFICATION

Check that the response happened and that the security objective was actually achieved.
